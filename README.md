# Tenzies Game 🎲

A simple Tenzies game built to practice and learn full-stack development. The goal of the game is to roll dice until all of them show the same number. You can hold dice to keep their value while re-rolling the others.

## How to Play:
1. Roll the dice by clicking the "Roll" button.
2. Click on a die to "hold" its value.
3. Keep rolling until all dice show the same number!

## Features:
- **Roll Dice:** Roll and hold dice values to win.
- **Dice Persistence:** Dice remain held until toggled.
- **Reset Option:** Start a new game anytime.
- Future Features (Planned):
  - Timer to track how fast you win.
  - Leaderboard to track best scores.
  - Save game progress.

## Installation:
To run the game locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/username/tenzies-game.git
   cd tenzies-game
2. Install dependencies:
   npm install
3. Start backend server:
   npm run start
4. Start frontend:
   npm start
5. Open http://localhost:3000 in your browser
